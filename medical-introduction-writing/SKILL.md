# 医学 SCI 前言写作

本 Skill 只处理原创医学研究论文的 Introduction，可用中文说明、中文写作或英文写作。它把研究信息、文献证据、段落框架、逐段草稿、逐句核对和语言修改分成六个可交接阶段。核心原则是可追溯性和科学含义优先于流畅性；AI 负责整理、起草和提出修改，作者负责确认研究定义、证据和最终文本。本 Skill 不替代作者判断，不保证发表，不扩展到 Methods、Results、Discussion 或统计分析。

## 启动与阶段交接

1. 先判断用户要求的是完整六步流程还是单独某一步，并盘点当前对话中已有的研究资料、文献层级、目标期刊、语言和篇幅。已有且可读取的材料不要求重复提供。
2. 只把作者已确认的上游内容作为下游输入。每一步输出“本步结果、材料依据、待核实事项、需要作者确认的交接状态”；上游未确认时，说明缺口并停在当前步。
3. 发现上游存在会改变研究含义的冲突（例如摘要与方法的结局定义不同、研究设计与目的不符、文献适用人群不同），指出冲突及依据，暂停受影响的下游任务，请作者决定如何纠正；不得静默回改。
4. 资料不足时可以给出明确标记的临时整理、框架或草稿，但不得称为已完成证据核验，也不得用推测填空。详细证据等级和表述强度见 [references/evidence-rules.md](references/evidence-rules.md)。
5. 默认只输出当前阶段必要内容；不要生成与任务无关的中间表、脚本或整篇引言。引用编号沿用用户提供的编号，不凭空添加、重排或替换。

## 六步工作流

### 1. 明确研究问题

输入可以包括题目、摘要、方法、数据来源、变量定义、已有结果或图表说明。提取研究对象与场景、设计、暴露或关注因素、主要结局及其测量、预设研究目的；将探索性分析和待确认内容分开。先用一句话概括研究问题，再用表格列出“项目、整理结果、材料依据或待补充信息”，最后按优先级列出待核实事项。结果不得从显著性或已有结果倒推出预设假设；关联性研究使用“相关、关联、差异”等设计相符表述。

### 2. 整理可追溯的文献证据

只使用用户提供或明确授权检索的文献。逐篇记录文献标识、核验层级（全文、摘要或仅书目信息）、原文位置、主要发现、适用人群/设计/结局/测量条件、限制及可支持的具体主张。比较研究间一致与分歧，区分证据不足和真正未解问题；文献真实存在不等于支持当前句子。无法定位原文时标为“待核实”，不能编造 DOI、数据、效应量或原文位置，也不能凭少量文献宣称研究空白。

### 3. 拟定引言框架

根据已确认的研究问题、证据表和期刊要求，组织从背景、已有证据、限制或未解问题到本研究目的的论证链。可以合并或拆分段落，不固定段落数量。输出“段落、论述任务、核心主张、支持文献、与下一段的衔接、建议篇幅及缺口依据”表。每段应有独立任务；研究缺口必须有证据且属于本研究设计能够回应的范围，不能把“研究较少”或“样本量较小”本身当作必要性。

### 4. 分段起草并标记待核实项

每轮只起草作者指定的一段。先说明本段任务，再基于已确认框架和文献写草稿；需要证据的主张后保留用户文献编号，另列“待核实/缺少材料/衔接问题”。参考例文只借鉴组织方式和语言，不能迁移事实或引用。不改变设计、变量定义、数据或结论强度，不把观察性关联写成因果，不自行增加研究目的或结论。

### 5. 内容与引用三方核对

输入为草稿、研究原始资料和对应文献原文（或明确的摘要级材料）。按句编号并列出“原句、表述类型、核对结果、实际依据/原文位置、问题、最小修改建议”。核对结果只用“支持、部分支持、不支持、无法核实、不需要引用”；分别检查人群、设计、时间、指标定义、数字、统计结果、因果措辞、研究缺口和研究目的。只有能定位到所给材料时才标“支持”；摘要不能冒充全文，无法核实时说明缺少什么。严重科学问题未解决时，不得标记为已通过，也不要在本步重写全文。

### 6. 语言修改与引用保留

只对第五步已核对或明确保留的文本进行语言和衔接修改。输出优化后的引言、主要修改说明（术语、长句、重复、过渡）和仍需作者确认的问题。保留引用与主张的对应关系及待核实标记；不新增事实、文献、研究缺口或贡献，不改变研究对象、设计、变量定义、数据、因果含义、结论强度或删去未核实信息。完成后对照原稿检查科学含义、数字和引用是否变化。

## 研究设计与范围约束

根据研究设计调整推断强度：横断面、病例对照和一般观察性研究默认使用关联表述；随机试验可在分配、方案和分析集支持时描述干预效应；诊断研究区分参考标准、敏感度/特异度和预测值；预测模型区分开发、验证、校准和预测性能。若用户要求把关联改成因果或把不显著结果改成确定有效，明确拒绝该改写并保留原始含义。任何超出 Introduction 的请求，说明范围并只完成与前言直接相关的部分。

## 引用与证据细则

遇到需要判断证据强度、原文定位、研究设计表述或“研究空白”的任务，先读取 [references/evidence-rules.md](references/evidence-rules.md)。遇到行为测试、回归测试或需要复现验收标准的任务，读取 [references/validation-cases.md](references/validation-cases.md)。
