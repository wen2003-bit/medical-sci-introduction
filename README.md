# 医学SCI前言写作

`medical-introduction-writing` 是一个面向医学、临床研究、流行病学和公共卫生原创研究论文 Introduction 的 Codex Skill。它支持中文说明以及中文或英文引言写作，重点帮助作者把研究问题、文献证据、段落逻辑和引用核查组织成可交接的工作流。

## 六步工作流

1. **明确研究问题**：从题目、摘要、方法和已有结果中提取研究对象、设计、变量、结局和预设目的，区分探索性分析与待确认内容。
2. **整理可追溯的文献证据**：记录文献标识、核验层级、原文位置、适用范围、限制和可支持的主张。
3. **拟定引言框架**：安排背景、已有证据、未解问题和研究目的的论证顺序，匹配文献并说明段落衔接。
4. **分段起草**：每轮只起草指定段落，保留引用对应关系，单独标记待核实内容。
5. **内容与引用核对**：逐句检查事实、数字、研究设计、结局定义、因果措辞和引用支持程度。
6. **语言修改与引用保留**：在核对基础上精简语言、统一术语、改善衔接，同时保持科学含义和引用关系不变。

每一步都输出当前结果、材料依据、待核实事项和交接状态。上游信息未确认或存在会改变研究含义的冲突时，Skill 会暂停受影响的下游工作，等待作者决定如何处理。

## 安装与调用

将 `medical-introduction-writing/` 文件夹复制到 Codex 可发现的 skills 目录（例如 `~/.codex/skills/`），保留 `SKILL.md`、`agents/openai.yaml` 和 `references/`。

显式调用：

```text
使用 $medical-introduction-writing 按六步流程处理这篇医学研究的 Introduction。
```

也可以直接用自然语言请求撰写、核查或修改医学论文 Introduction；当任务范围匹配时，Skill 可被自动发现。请提供可核实的研究资料、文献原文或明确的摘要级材料，以及语言、篇幅和期刊要求（如有）。

## 适用范围与限制

本 Skill 只处理原创研究论文的 Introduction，不替代作者的研究判断，也不扩展到 Methods、Results、Discussion、统计分析或投稿。它不会把文献存在等同于文献支持，不会编造文献、数据、原文位置或研究缺口；资料不足时会明确标记“待核实”或“无法核实”。观察性研究的关联不会被改写为因果，语言润色也不会改变数据、研究目的、结论强度或证据范围。

所有验证案例均为合成匿名材料，不代表真实发表研究。MIT 许可证见 [LICENSE](LICENSE)。
