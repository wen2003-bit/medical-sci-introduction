# 医学SCI前言写作

`medical-introduction-writing` 是面向医学、临床研究、流行病学和公共卫生原创研究论文 Introduction 的 Codex Skill。它支持中文说明以及中文或英文引言写作，按六步工作流逐阶段交接：明确研究问题、整理可追溯文献证据、拟定引言框架、分段起草、内容与引用三方核对、语言修改与引用保留。

## 方法来源与边界

本 Skill 依据用户提供的《AI辅助科研引言写作》PPT中的教学流程开发。PPT以产后抑郁症状研究为演示案例，并明确提示案例信息和阈值仍需回到原始研究核实。PPT、截图、论文全文和未获授权的合作人员资料不随本项目发布；这里仅作方法来源说明，不表示已获得相关材料的公开转载许可。审计后分为三类：

- **保留的核心方法**：六步顺序、研究信息/证据表/段落框架/带引用草稿/核对表/终稿的阶段交接；每轮限定任务；作者确认后再进入下一步；逐句核对并保留引用。
- **为通用性和严谨性补强的规则**：全文与摘要级证据分层；原文位置和适用范围记录；设计匹配的推断强度；定义冲突时暂停；研究缺口必须可由本研究设计回应；语言修改保留科学含义的不变量；支持自然语言和单步调用。
- **仅属于案例的内容**：产后 6 周、EPDS 阈值、沈阳单中心、1,065 名产妇、孕期增重非线性关联及案例中的工具/医院信息。这些不会被写成通用医学规则，且不能替代原始研究核验。

PPT是教学材料，不是已完成的实证验证；本 Skill 不声称已经证明能提高论文质量或保证发表。

本 Skill 只处理 Introduction，不替代作者的研究判断，不把文献存在等同于文献支持，不承担万能的造假检查，也不自动联网检索或扩展到 Methods、Results、Discussion、统计分析或投稿。

## 安装与调用

将 `medical-introduction-writing/` 文件夹复制到 Codex 可发现的 skills 目录（例如 `~/.codex/skills/`），保留其中的 `SKILL.md`、`agents/openai.yaml` 和 `references/`。可显式调用：

```text
使用 $medical-introduction-writing 按六步流程处理这篇医学研究的 Introduction。
```

也可以直接用自然语言请求协助撰写或核查医学论文 Introduction；当主题和范围匹配时，Skill 可被自动发现。请提供可核实的研究资料、文献原文或明确的摘要级材料，以及语言、篇幅和期刊要求（如有）。

## 限制

资料不足时输出会保留“待核实”或“无法核实”，不会用猜测补齐。上游研究定义存在重大冲突时，下游工作会暂停，需作者确认后继续。语言润色不会新增未经核实的事实、文献、研究缺口或因果含义。
